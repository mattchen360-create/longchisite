# LONGCHI 动效优化

设计方向：沿用龙弛蓝 #0028A0、黄 #F8B000、深蓝 #001A66、白与浅蓝。既有 Manrope 字体与 20 个候选章节保留。动效用于解释切换、呈现真实图片和提供操作反馈；不添加光点、连接线、玻璃小卡或虚构数字。

重点：Banner 同一区域双图衔接并按切换方向揭幕，标题逐行进入、正文与行动按钮随后到位；页码的选择底色平滑移动。照片只在桌面细指针下随滚动产生有限深度，两处重点照片有一次性的裁切展开。四产品线的描述平滑展开，场景图连贯切换。按钮、箭头、菜单和弹窗在操作时给予短促反馈。

约束：不滚动劫持，不强制停靠，不让主体图片或标题依赖 JS 才可见。不自动轮播，不添加产品/照片叠加小卡。手机保持手动横滑和正常纵向滚动。系统减少动态设置生效时关闭位移、揭幕和视差；动态设置在使用中改变也必须响应。JavaScript 监听、观察器、动画和计时器要在离开首页时清理。

图片和产品事实不改动，联系、询盘、视频、相册、方案切换和筛选工具继续可用。

实现集中在 `app/motion.css`、Banner 组件与 `components/home-motion.tsx`。图片增加裁切窗口，原有照片高度保持一致；滚动只更新可视区域内图片，使用被动监听和单次 requestAnimationFrame 调度，无持续空转循环。

正式构建和 TypeScript 通过。浏览器检查通过：Banner 正反方向揭幕、快速切换、键盘与手机横滑、当前和上一张图衔接、指针景深、照片随滚动变化、原图片布局、四产品线 CTA、使用中改变减少动态设置，以及 320/390/768/1024/1440px 的四张 Banner 无横向溢出。微信、相册焦点返回和筛选页切换已检查。动效均为有限时长或响应操作，不依靠隐藏整页内容来实现。

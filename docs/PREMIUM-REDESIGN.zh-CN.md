# LONGCHI 整站视觉重设计

目标：从模块齐全的官网升级为有鲜明行业品牌感的完整体验。保留用户认可的蓝黄配色与企业信息准确性，重做首屏、叙事节奏、导航、产品/方案、企业与交付展示、移动端和交互细节。

## 同行参考

实时查阅官方 [Schréder](https://www.schreder.com/)、[SWARCO](https://www.swarco.com/)、[SKIDATA](https://www.skidata.com/home)、[dormakaba](https://www.dormakaba.com/)；另由独立浏览器任务检查首屏和下方板块截图。只参考构图、信息组织与交互，不复制同行图片、客户、业绩、案例或功能主张。视觉优劣为审美判断，不以测试通过推断客观领先或转化提升。

## 视觉计划

- 颜色：品牌蓝 `#0028A0`、亮蓝 `#0070E8`、黄 `#F8B000`、深蓝 `#001A66`、白 `#FFFFFF`、浅蓝 `#F2F7FF`。深蓝用于图片对比与深色章节，白字在深底保持阅读；不重引入灰绿、蓝紫光晕或装饰连接线。
- 字体：继续自托管 Manrope；首屏以大幅字形与全景图片建立主次，正文 16–18px，页面标题与小标签不再采用几乎相同的模板节奏。
- 布局：全幅场景首屏 → 大字品牌介绍 → 四方案纵向交互索引 → 真实企业制作/技术叙事 → 可比较的型号展厅 → 应用与项目助手 → 项目交付过程 → 技术资料与咨询。以全幅图片、窄文案、产品近景和深色章节交替，去掉每节都同样的两栏卡片感。
- 特效：一段克制的首屏入场；细微鼠标视差仅在精细指针和非减少动态时生效；用户切换的图像过渡、方案展开、完整照片画廊、可键盘操作的导航。内容不依赖动画才能出现，移动端不强制粘滞滚动，不自动轮播。
- 导航：清晰 Home、可展开的四方案大菜单、移动端抽屉；稳定的项目咨询入口。
- 企业证据：只用供应实拍、明确公司主体，不用虚构人数/面积/资质/客户来营造规模。新蓝调建筑图属于应用示意。
- 项目交付：梳理需求、配置、供货与交付/资料的讨论节点，增加交付需求咨询模板；不承诺未确认的运费、交期、贸易条款或全球仓库。

## 自查修订

“多加几个模块”和把所有区域都做相同淡入，不足以满足本目标。重点改为整体构图、真实与示意的视觉分工、精细的字号与留白，以及有用途的交互。原有对比、项目助手、文件下载、后台持久化和同意测量继续可用。

验收需要实测首屏与完整页面、手机/平板/桌面、四方案与导航、比较/画廊/项目助手、减少动态、询盘保存、构建、部署和 GitHub 同步。不是仅检查 CSS 或只看一个首屏截图。

## 本地验收结果

- 正式构建通过，TypeScript 通过，原有 6 项询盘验证测试通过。
- 正式构建预览的 16 条主路由在 360 / 768 / 1440px 下通过 HTTP、单一 H1、Home 入口、文档无横向溢出、已载入图片和四个 LP noindex 检查。
- 方案键盘切换、导航大菜单、手机抽屉、照片方向键/Esc/焦点返回、真实型号比较、交付模板、国家/时间/多线咨询传递和减少动态检查通过。
- 本地 API 集成检查通过：实际保存、去重、联系许可、来源拦截、广告同意字段、后台登录、状态更新和退出；只使用 .test 测试资料。
- 正式构建浏览器控制台：0 errors / 0 warnings。开发时截图工具在页面完成水合前修改 caret 样式曾产生差异提示；等待交互就绪后的正式构建未复现。
- 人工复核桌面首页/全页、企业页、方案页和手机首页/型号页/联系页截图；修复型号横滑区绝对定位隐藏文本导致的溢出、过大隐私提示标题，并将手机联系表单前置。

这些检查证明布局与功能可用，不代表广告 CTR、实际海外网络性能或询盘转化已有统计结论。投放效果需在正式域名、素材与测量配置就绪后验证。

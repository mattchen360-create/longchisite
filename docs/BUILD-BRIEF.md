# LONGCHI SMART website brief

The user approved a new English website for overseas SEM, with four equal product lines: smart lighting, traffic safety, smart parking, and access control. Target markets are Europe, America and Australia. Assets and specifications will be supplemented gradually.

Design: white primary canvas, LONGCHI blue #0028A0 for copy, restrained yellow #F8B000 structural accents, original supplied logo. Manrope is a provisional interface typeface, not an official brand font. Use actual supplied equipment images, restrained borders, clear hierarchy and generous space. Avoid invented case studies, testimonials, certifications and performance claims.

Architecture: brand homepage, four substantive solution pages, four dedicated paid-search landing pages with focused navigation, model pages, resources, contact, privacy, a real enquiry endpoint and private lead management. Content should remain editable from a small content module with original source provenance.

Acceptance: accessible mobile and desktop layouts, model URLs that survive direct visits, unique metadata, valid robots/sitemap, enquiry persistence before success, no external measurement scripts without relevant consent, no personal information in analytics events, signed administrator sessions, successful production build and documented handover.

The first visual version was rejected by the user. The active visual direction is docs/REDESIGN-BRIEF.md: photographic application scenes, direct four-line positioning, larger readable typography, stronger yellow quotation actions and equal category selectors. Illustrative generated scenes are labelled and are separate from product evidence.

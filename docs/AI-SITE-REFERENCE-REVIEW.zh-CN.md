# LONGCHI 海外 SEM 站：AI 建站官网参考观察

观察日期：2026-11-11。范围：公开官网实时页面内容和 1440×1000 桌面首屏截图，未登录、未使用付费编辑器，也未测量转化效果。以下“观察”为可见页面事实，“建议”为针对 LONGCHI 的设计推导。

补充阅读：[Lovable](https://lovable.dev/)、[Bolt](https://bolt.new/)、[v0](https://v0.app/)。Lovable 的官方页面文本可读取，浏览器出现访问挑战，未尝试绕过；其视觉未作完整实测。Bolt、v0 的公开首页也已保存截图。v0 将主要任务集中在创建入口，并提供模板和示例；此处借鉴任务清晰度，不复制聊天输入框。所有观察限于公开展示站，不代表各平台生成网站的质量上限。

## 本轮实施方案

- 色彩：LONGCHI 蓝 `#0028A0` 用于正文、亮蓝 `#0070E8` 为辅助、黄 `#F8B000` 用于选中与行动；冰蓝 `#EAF2FF`、浅紫 `#E8E5FC`、暖浅色 `#F5EDDD` 构成用户要求的非纯白背景。
- 字体：复用自托管 Manrope；大标题表达整体场景，型号与说明保持短而明确。
- 构图：上方非对称标题与主行动，下方单一大型园区模型；四条标签等权，右侧联动真实设备，下沿为多产品线项目清单。手机保持完整模型，设备面板移至下方。
- 区别于通用模板的重点：访客直接在园区理解四类设备的位置，再选入项目需求；示意场景与真实产品图分开标注，避免把概念图当工程案例。
- 交互：标签、热点同步；支持方向键、Home / End；点击添加、删除产品线，继续后将有效产品线名称和可编辑需求模板带入询盘。切换和打开清单记录为探索事件；成功询盘事件仍仅在后台保存成功后触发。
- 克制：不自动轮播、不模拟 AI 对话、不添加无依据评价与数字；仅在用户主动切换后轻量过渡，尊重减少动态设置。

## 七项直接可执行建议

1. **用一个独有的“智慧场景舞台”替代通用首屏卡片墙。** 左侧大标题和一句采购价值说明，右侧是有纵深的应用场景与真实产品图；底部常驻四个等权切换入口：Lighting / Traffic / Parking / Access。切换时同步场景、编号、产品与 CTA 文案，保持主要按钮的位置稳定。
2. **把丰富渐变当作整页光环境。** 使用冰蓝、浅紫和淡暖黄的连续环境光，LONGCHI 蓝仍用于文案，黄色用于动线、序号、焦点与 CTA。文字区域用受控的浅色底保证阅读；避免每块卡片都有独立彩色玻璃背景。
3. **创作贯穿页面的品牌动线。** 从首屏黄色细线、节点或道路轨迹出发，连接四种场景的热点，再自然延伸到产品选择和询盘区。该图形表达连接与系统协作，不能模拟实际项目拓扑或暗示未经证实的互联能力。
4. **用可操作场景证明“有创意”。** 允许用户点选产品热点，显示对应产品、适用环境与查看方案入口；键盘可操作，手机端改成清晰分步选择。无需把 B2B 访客带进无实际作用的聊天框或复杂 3D 操作。
5. **让四条产品线同时清楚，又让每次广告点击有明确目的地。** 首页四条入口等权；四个专属落地页分别承接不同产品广告。某条广告落地页直接展示该线标题、图像与询盘目的，不要求用户先从首页重新选一次。
6. **用大幅展示和节奏变化建立高级感。** 首屏采用一个大场景，下一屏是四条产品线，再接一张横向方案展示；交替使用大画面、清晰短文本和少量细节卡，避免整页相同圆角盒子。保持显式 Home 导航、稳定询盘入口与清晰当前位置。
7. **让互动帮助询盘，并给后续资料留位置。** 产品线或项目类型选择可带入询盘表单，减少重复填写。真实参数、认证、案例暂缺时保留内容插槽或省略相关模块；产品实拍和真实规格必须与原材料一致。动画只做轻量场景过渡、热点呼吸、按钮反馈；尊重减少动态设置，移动端减少特效。

## 三个需要避免的陷阱

- **把炫酷等同于满屏动态。** 自动轮播、大面积 WebGL、粒子和过度视差会使采购人员错过产品与 CTA，也增加移动端加载负担。优先让访客主动切换，基础页面在无动画时仍完整。
- **把模板结构和品牌素材一起搬过来。** 不复制这些平台的 logo、客户标志、用户数、评语或界面；不可把 AI 示意场景当真实工程案例。参考构图、交互逻辑和信息节奏，建立 LONGCHI 自己的场景语言。
- **以视觉推断 CTR 或转化提升。** 页面创意不能保证广告点击率；CTR 还涉及广告素材、关键词和投放。上线后以有效询盘、表单完成和落地页行为验证，并让点击事件与成功提交事件分开记录。

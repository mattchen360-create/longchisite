# 品牌版交互增强

前提：用户认可当前龙弛蓝 `#0028A0`、亮蓝 `#0070E8`、黄 `#F8B000`、浅蓝/白内容区。保留 Banner、Logo、无装饰连接线的版式和现有企业信息，继续使用自托管 Manrope。

本轮选用三项实际采购任务驱动的 HTML 交互：

1. 产品展厅：四产品线切换，照明/交通直接浏览现有型号，最多对比同一产品线 3 个型号。比较值来自 `content/site.ts`；缺失字段写明未列出，不推断没有该功能。停车与门禁沿用类目资料，不编造型号。
2. 企业实拍画廊：在现有能力展示区打开原有实拍大图，支持前后浏览、Esc 关闭及焦点返回。图片与实体来源标注不变，不包装成虚构的 360 度工厂漫游。
3. 项目需求助手：选择应用、产品线、国家和计划时间，生成可编辑的咨询提纲，再进入现有询盘。这里不采集邮箱或手机号，不提供虚构报价或自动兼容承诺。

构图：产品展厅替换重复的四张场景卡；企业照片增加放大入口；需求助手为两栏的选择与提纲。使用品牌色表明当前选择，以间距与图片建立层级，保持已有页面节奏。减少重复说明与无用的动画，避免新增相似卡片墙。

查询预填只接收允许的应用、产品线、国家和时间值。成功询盘仍需后台实际保存，浏览、比较和生成提纲不得计为成功询盘。

验证覆盖：四产品线切换、照明/交通数量、同线最多 3 款比较、字段原值与同义标题分组、型号咨询预填、应用建议后手动删除产品线、国家与时间传递、未知值忽略。两种 dialog 已检查 Esc、方向键和焦点返回。360、390、768、1024、1440px 均未发现文档横向溢出；手机比较表在模态框内部横向滚动。

本地浏览器使用 `.test` 邮箱提交 Commercial property / Australia / 3–6 months / lighting + parking 的咨询，并从受保护后台读取记录，核实这些值真实持久化。未向他人发送消息。Banner 配色仍为原龙弛蓝，企业照片与参数没有改造或杜撰。
